# EpiCare
Wearable AI for epilepsy: forecasts seizure risk from smartwatch signals and seizure cycles, and detects convulsive seizures from the wrist accelerometer to alert caregivers. The forecast acts as a prior that tunes the detector. Built on My Seizure Gauge and SeizeIT2, evaluated with SeFEF.

* `branch1/`: seizure risk forecasting (Python package, notebook, tests).
* `branch2/`: convulsive seizure detection (Python package, tests); see `branch2/README.md`.
* `app/`: mobile app (installable on iPhone and Android) that shows the results; see `app/README.md`.
